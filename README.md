# Skiglede

Smøreapp for langrenn: komplett Swix-smøring for en bestemt løype, bygget opp fra grunnsmøring til topplag, basert på værdata, høyde og soleksponering.

Første mål: Hovden. Se [docs/regelspesifikasjon.md](docs/regelspesifikasjon.md) for regler, datakilder og åpne punkter.

Planlagt stack: Expo (web først), Neon (Postgres + PostGIS), delt regelmotor i TypeScript.
